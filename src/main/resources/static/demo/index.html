    ¿Qué estoy probando exactamente?＋

    Este panel envía eventos reales a tu API local. Recibido significa que la evidencia quedó guardada. El worker convierte eventos normalizados en transacciones. Procesado confirma el registro; consulta el estado tras unos segundos.

    “Repetir el mismo envío” reutiliza los bytes y la clave de idempotencia del último intento. “Nuevo evento” genera una clave diferente. Si se pierde la conexión, repite el intento anterior para evitar duplicados.

    La clave, la configuración y la actividad permanecen en memoria. Recargar o cerrar la página borra la sesión visual; los eventos aceptados permanecen en PostgreSQL. No hay conexión con Nu ni cargos bancarios.
